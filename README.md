# Generator liczb losowych

Serwis API + aplikacja webowa do losowania liczb. Udostępnia kilka metod losowania,
a jako ziarno może posłużyć szum z kamery lub mikrofonu komputera.

> Status: początkowa struktura repozytorium.

## Struktura

```
backend/    # API w Pythonie
frontend/   # aplikacja webowa
docs/       # kontrakt API i schemat bazy danych
```
